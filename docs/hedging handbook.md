## If you have an old citation

Citations written before #246/#289 pointed at specific lines in this file
(e.g. `docs/hedging handbook.md:2032`). This file no longer has that
content, so those line numbers won't resolve here. The handbook as it stood
at the moment of extraction — same content, same line numbers — is
preserved at the **`handbook-v1.0`** tag in the new repo:

<https://github.com/qwertytam/deltadewa-handbook/tree/handbook-v1.0>

Citations added since #289 use the handbook's own section anchors instead
of line numbers, which survive edits to the new repo; see any current
citation in this codebase (for example in `deltadewa/analysis/`) for the
pattern.
